# AI Coding Anti-Patterns

- patch stacking
- `DashboardV2` / `NewButton` / `final2`
- duplicate sources of truth
- fake success with mocks/placeholders
- old-stack remembered APIs
- changing tests to fit broken behavior
- copy-pasting shared components
- framework upgrades as a side effect
- frontend-only authorization
- deleting legacy before migrating consumers
- keeping legacy forever after migration
- giant one-pass rewrites
- "code looks right" used as runtime evidence
