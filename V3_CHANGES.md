# v3 Changes

Compared with v2:

## Added critical safeguards
- generated-file/source-of-generation rules,
- monorepo/workspace discovery,
- imported skill supply-chain review,
- deeper security references,
- production incident workflow,
- reliability/resilience,
- environment/config management,
- privacy/data governance,
- feature-flag cleanup lifecycle.

## Improved autonomy
- thin one-time bootstrap installer,
- no duplicated master rules,
- router escalation for new risk categories.

## Improved verification
- concrete behavior contracts for every skill,
- deterministic eval result grader,
- official `skills-ref` wrapper when installed,
- one-command self check,
- browser server/HTTP/optional Playwright helpers,
- generated-file and workspace audit scripts.

## Kept intentionally out of universal core
- large cloud/provider catalogs,
- database/framework-specific packs not detected in the project,
- heavy E2E/visual tooling when the repository already has a different established tool.
