# Site Architecture

Establish:
- product,
- target user,
- main action,
- business flows,
- known pages,
- references.

For each page define:
- purpose,
- primary CTA,
- sections,
- content requirements,
- entry/exit flow,
- dependencies.

Also define shared navigation, global chrome, shared components, and build order.
