# Architecture Review

Review:
- module boundaries,
- state ownership,
- data flow,
- APIs/contracts,
- database ownership,
- shared abstractions,
- coupling,
- duplication,
- permissions,
- failure handling,
- deployment constraints.

Recommend the smallest structural correction that resolves the actual problem.

Do not recommend a rewrite because imperfection offends aesthetic sensibilities.
