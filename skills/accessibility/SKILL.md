# Accessibility

1. Prefer semantic native elements.
2. Ensure accessible names.
3. Verify keyboard access.
4. Verify visible focus.
5. Manage dialog/menu focus.
6. Associate labels/errors with inputs.
7. Do not convey meaning only by color.
8. Check contrast.
9. Make dynamic state understandable.
10. Avoid custom controls when native controls suffice.
