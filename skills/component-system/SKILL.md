# Component System

1. Search for existing primitives.
2. Determine which are canonical.
3. Repair/extend them when coherent.
4. Build missing primitives only when real usage requires them.
5. Include relevant interaction states.
6. Keep APIs small and predictable.
7. Do not create page-specific forks.
8. Import/reuse Navbar/Footer/shared components rather than copying code.

Build once, reuse by import/reference.
