# Backend Engineering

1. Identify trusted boundary.
2. Validate server input.
3. Authenticate where required.
4. Authorize resource/action.
5. Apply business rules.
6. Perform data operation.
7. Handle external failures.
8. Return intentional errors.
9. Add useful non-sensitive observability.
10. Consider idempotency/races.
11. Test success/failure.

Check ownership, transactions, duplicate requests, partial failure, retries, and data consistency.
