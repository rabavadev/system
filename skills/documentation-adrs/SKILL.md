# Documentation and ADRs

## Update docs when change affects
- setup,
- environment variables,
- public/internal contracts,
- architecture,
- operations,
- migration procedure.

## ADR for important decisions
Capture:
```text
Context
Decision
Alternatives considered
Consequences
Migration/compatibility notes
```

Use ADRs for decisions future agents might otherwise "improve" back into a rejected architecture.
