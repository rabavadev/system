# Design System

1. Inspect existing token/theme sources.
2. Inspect canonical shared components.
3. Reuse existing values where appropriate.
4. Do not invent a parallel token system.
5. If none exists, establish a minimal system from real product needs.
6. Promote repeated UI only after a real pattern exists.
7. Update canonical primitives instead of creating `ButtonV2`.
8. Verify affected pages remain one product.

Project-specific colors/fonts/spacing belong in `PROJECT_RULES.md`.
