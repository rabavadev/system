# React Best Practices

- keep state close to clear ownership,
- avoid duplicated derived state,
- use effects for synchronization with external systems, not routine derivation,
- avoid unnecessary memoization,
- keep component boundaries meaningful,
- preserve stable keys,
- avoid prop/state mirrors,
- use current installed React patterns, not remembered legacy conventions.
