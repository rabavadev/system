# Uploads and Webhooks Reference

## Uploads
Consider:
- content/type validation,
- size limits,
- storage permissions,
- filename/path handling,
- executable content,
- public/private access,
- processing isolation.

## Webhooks
Consider:
- signature/auth verification,
- replay protection where relevant,
- idempotency,
- event ordering,
- duplicate delivery,
- secret rotation,
- failure/retry behavior.
