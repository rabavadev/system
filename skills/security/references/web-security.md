# Web Security Reference

Review as relevant:
- server-side authorization,
- injection/query construction,
- XSS/output encoding,
- CSRF for cookie-authenticated state changes,
- CORS configuration,
- redirect validation,
- SSRF/internal URL fetching,
- security-sensitive headers,
- rate limiting/abuse controls,
- session/cookie properties.

Do not add controls blindly. Match the actual architecture and threat boundary.
