# Game Development

Inspect engine/framework, language, platform, game loop, and architecture first.

Consider:
- game feel,
- motivation,
- difficulty curve,
- fairness,
- progression,
- scope creep,
- frame rate/memory/draw calls,
- scaling entity counts,
- state machines/component systems,
- whether an LLM is actually appropriate.

For procedurally generated or puzzle levels intended to be winnable:
- validate solvability,
- prevent impossible states,
- increase difficulty without eliminating all valid solution paths.
