# Page Builder

1. Inspect active route.
2. Inspect current page.
3. Inspect shared layout/navbar/footer by import.
4. Inspect canonical design system.
5. Identify primary user action and sections.
6. Modify active implementation.
7. Reuse shared components.
8. Cover states/responsive behavior.
9. Verify navigation/actions.
10. Remove obsolete page implementation after replacement.

Never create `PageV2` merely to avoid editing current code.
